# admin META

- Post-auth dashboard surfaces.
- Sidebar menu + topbar come from this layout.
- Subdirs are functional groups: `ext` (per-extension admin), `extensions` (extension registry), `media` (R2 library), `settings` (ext settings), `users` (admin user mgmt), `roles` (1.50.0: roles and access — presets read-only, custom roles as a per-page None / View / Edit matrix).
- Extension-specific dashboard tiles come from `extensions/<id>/admin/` (code extensions) or `adminPages` in declarative manifests.
- Dashboard (`page.tsx`): the plugin section comes first when any plugin has cards. `ext/dx/dashboard-widgets.ts` loads them (declarative `dashboardCards`, `dashboardWidgets`, and the deprecated `dashboardStats` / `dashboardRevenue` through adapters) with the period from the URL (`lib/report-period.ts`); `components/admin/dashboard/widget-cards.ts` writes numbers for their unit (`lib/units.ts`, site currency `core.currency`) and the change against the previous period; `PluginSection.tsx` lays out number cards (`ExtStatCard`), daily charts (`TimeseriesCard` with `widgets/TimeseriesChart`), proportions (donut / bar list presets), then lists (`ListCard`, next to declarative recent cards), with one `ReportPeriodControl` for the page.
- `users/`: `users-data.ts` loads everyone plus the plugins' member facets (`Extension.memberFacets`, see `src/ext/member-facets.ts`); `users-filter.ts` is the one filter the page and `GET /api/users/export` share (search, dates, role, facets); `UserFacetSections.tsx` draws a facet's lines and links in the member sheet.
- Money on admin pages (1.63.0): client components read the site currency (`core.currency`) from `components/CurrencyProvider.tsx`, provided by the root layout next to the time zone; server components render `<MoneyText amount>`. commerce-kit's order list shows each order's checkout fields (`meta`) with the labels their plugins declare.
- Lists on phones (1.64.0): `CoreTable` takes `cards` and draws one card per row below 640px (`components/admin/core-row-cards.tsx`); member-facing pages that reuse admin workspaces pass it, admin lists may.
