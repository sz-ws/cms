# src META

- `src/app/`: Next.js App Router surfaces (admin, public, API)
- `src/components/`: shared presentational + intent UI primitives
- `src/ext/`: extension runtime (capability + provider + declarative layer)
- `src/lib/`: framework glue (db, auth, security, rate-limit, cf env)
- `src/hooks/`: shared client-side hooks

Each subdir owns its own META.md; this file is only the index.
